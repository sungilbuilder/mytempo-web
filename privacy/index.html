개인정보처리방침

시행일 및 최종 수정일: 2026-08-19

MYTEMPO(마이템포, 이하 "앱")는 이용자의 개인정보를 소중히 다룹니다. 본 방침은 앱이 어떤 정보를 어떻게 다루는지 설명합니다.

1. 수집하는 정보

앱은 별도의 계정 가입이나 로그인을 요구하지 않으며, 서버에 개인정보를 전송하거나 수집하지 않습니다. 앱의 모든 기능은 이용자의 기기 안에서만 동작합니다.

2. 카메라(사진 라이브러리) 접근

이용자가 "내 스윙 등록" 기능을 사용할 때, 기기에 저장된 영상을 선택할 수 있도록 카메라 롤(사진 라이브러리) 접근 권한을 요청합니다. 선택된 영상은 기기 내부에서만 처리되며, 외부 서버로 업로드되지 않습니다. 앱은 이용자가 명시적으로 선택한 영상에만 접근하며, 전체 사진 라이브러리를 스캔하지 않습니다.

3. 데이터 저장

템포 마킹 결과(구간 시간, 비율, 이름 등)와 연습 기록은 기기 내부 저장소에만 저장됩니다. 앱을 삭제하면 해당 데이터도 함께 삭제됩니다. 현재 버전 기준으로 클라우드 백업이나 기기 간 동기화 기능은 제공하지 않습니다.

4. 제3자 제공

앱은 어떠한 개인정보도 제3자와 공유하거나 판매하지 않습니다.

5. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동으로부터 개인정보를 고의로 수집하지 않습니다.

6. 문의처

개인정보 관련 문의: contact@mytempo.co.kr

7. 방침의 변경

본 방침은 기능 추가(예: 계정, 클라우드 동기화, 분석 도구 도입 등)에 따라 개정될 수 있습니다. 변경 시 앱 내 공지 또는 본 페이지 갱신을 통해 안내합니다.
